# Community conduct

Be respectful, constructive and welcoming. No harassment, personal attacks, discrimination, threats, doxxing or publication of private information. Critique code and ideas with clear evidence. Respect differences in language and experience.

Maintainers may edit/remove inappropriate contributions, close discussions or restrict access, proportionate to the conduct. Report concerns privately using GitHub's reporting tools or the repository owner's contact links. Do not post private evidence in a public issue. Maintainers should respond fairly, protect confidentiality and disclose conflicts of interest.
