# Roadmap

## 0.2 — interoperable daily use

- Real-device and live-Hermes compatibility matrix, including older versions and canonical authority mode.
- Incremental external-history synchronisation, pagination UI and search.
- Run event reattachment, polling/recovery after process death, unknown-execution acknowledgement with exact generation checks.
- Better tool timelines and clarification requests; keep approvals explicit.
- Database migration tests before schema version 2; optional database encryption and app lock.
- Fluent Chinese/pinyin review and stronger TalkBack/foldable validation.

## 0.3 — voice and automation

- On-device recognition preference, optional TTS and full-duplex voice when supported.
- Job create/edit/pause/resume only after capability checks and real integration tests.
- Shared-session attachment through documented gateway protocols, with ownership safeguards.

## Later

- Attachments/image UI, notifications and widgets.
- Advanced profiles, custom themes, Wear OS companion.
- Reproducible signed releases, dependency verification metadata and broader supply-chain checks.

No release dates are promised. Deferred controls are not presented as functional in the alpha.
