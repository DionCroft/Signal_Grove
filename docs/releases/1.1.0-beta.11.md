# Signal Grove 1.1.0-beta.11

Signal Grove 1.1.0-beta.11 is an Android preview for Hermes Agent, with optional on-device AI.

## Changes

- Chat shows reported Hermes activity for the matching run, including tools, subagents, waits, outcomes, timing, and the reported model and provider. Read-only history explains when reply text or activity is unavailable.
- Phone Chat shows the formatted prompt and reply budgets before sending. Phone history has direct date and model filters. Hermes context and compression are displayed when the server reports them.
- Supported servers can show bounded, read-only workspace previews for an attached conversation.
- Schedule previews show upcoming occurrences, time-zone offsets, and missed-run policy. Supported runtimes can review paused edits, approved project occurrences, and scoped run receipts.
- Compact layouts keep local document review, model search, helper consent, and draft handoff reachable with the Android keyboard open.

## Install or update

[Download the production APK](https://github.com/DionCroft/Signal_Grove/releases/download/v1.1.0-beta.11/hermes-agent-mobile-1.1.0-beta.11.apk). [GitHub release assets](https://github.com/DionCroft/Signal_Grove/releases/tag/v1.1.0-beta.11). Android 8 or later is required. On-device inference requires a compatible 64-bit phone and a separately installed model. If you already use Signal Grove, install this APK as an in-place update or turn on **Include preview releases** in Settings → App updates.

Version code 116 uses the same production package and signing certificate as beta.10. The published APK is 76,598,310 bytes. Its SHA-256, signing certificate, runtime SBOM, and provenance are included in the assets.
