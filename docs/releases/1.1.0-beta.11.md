# Signal Grove 1.1.0-beta.11 candidate

Beta.11 is in release validation. [Beta.10 remains available on GitHub](https://github.com/DionCroft/Signal_Grove/releases/tag/v1.1.0-beta.10).
The beta.11 candidate uses version code 116 and the existing production
package and signing identity. It supports Android 8 and newer. On-device
inference uses a compatible 64-bit device and a separately installed model.

## Changes under review

- Chat shows reported Hermes tools, subagents, outcomes and durations,
  with the model and provider for the matching run when available.
  Activity also shows when Hermes is waiting for an approval or answer, and
  whether the response is sending or its delivery is uncertain. Read-only
  history explains missing reply text and unavailable activity.
- Review phone prompt and reply budgets and which earlier material fits.
  Phone history has direct date and model filters. Hermes context and compression
  are shown separately when the server reports them.
- Open bounded, read-only workspace previews from an attached conversation
  when supported by the server and allowed for the connection.
- Review schedule occurrences with time-zone offsets and missed-run policy,
  preview paused edits, and inspect scoped run history and receipts on
  supported servers. Scheduled project writes require reviewed approval.
- Use Chat options beside the draft on compact screens. Open the setup helper
  with the keyboard visible and return to the same unsent draft. Compact
  layouts also cover document review, model search and reviewed handoff.

## Verification and compatibility

The private signed build from d6834a2 is 76,598,310 bytes. It uses the
beta.10 signer and passed 16 KB ZIP alignment and native inventory checks.
An Android 17 emulator upgrade from public beta.10 retained the app UID,
original installation time, Demo setting and a test task. Native diagnostics
use relative source filenames.

The corrected hosted build passed 1,243 JVM tests and 1,245 policy tests.
Both lint variants reported zero errors, and the hosted APK passed the
native path scan. The corrected native libraries passed the offline LFM3
prompt budget test on Android 17.
[Exact hosted workflow](https://github.com/DionCroft/Signal_Grove/actions/runs/45420870942).

The final-source Android matrix and production upgrade on the Xiaomi must
pass before publication. Live workspace and scheduler behavior depends on
the connected Hermes runtime and the enrolled worker. Those live gates are
tracked separately from fixture coverage. The qualified LFM3 phone context
ceiling remains 4K.
