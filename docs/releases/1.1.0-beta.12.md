# Signal Grove 1.1.0-beta.12

Signal Grove 1.1.0-beta.12 is a community preview for Android 8 and later.
The original-key APK updates existing production installations in place.

[Download the APK](https://github.com/DionCroft/Signal_Grove/releases/download/v1.1.0-beta.12/hermes-agent-mobile-1.1.0-beta.12.apk) · [Release assets](https://github.com/DionCroft/Signal_Grove/releases/tag/v1.1.0-beta.12)

## Changes

- Open offline setup from the phone chat composer. The compact layout
  gives the conversation more room and keeps the return control with the
  draft when the keyboard is open.
- Follow the open Hermes tool and see the reported MCP server, resolved
  skill, event times, receipt times and subagent outcomes in Activity.
- Supported Windows workers verify the reviewed checkout at reservation,
  claim, and launch. The scoped receipt route can recover a previously
  approved run after reconnect.
