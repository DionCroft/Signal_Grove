# 0.2.0 — Sessions, local tasks and scheduled jobs

- Conversation browser with search, paginated server listing, local pin/hide controls, capability-gated server rename and confirmed deletion. Unknown/active turns cannot be deleted through the conversation controls.
- Settled session history refreshes from paginated server history using stable message IDs. Atomic replacement removes obsolete/duplicate local rows, retains compression continuation IDs, and refuses to overwrite a newly active turn. Failed imports leave the saved transcript intact.
- Task notes, case-insensitive title/notes search, open/completed/overdue filters and due-date/priority sorting. Calendar comparisons use local dates.
- Read-only Hermes job listing/details with enabled state and supplied run timestamps. Profile/credential-partitioned snapshots remain readable offline and are visibly marked stale after errors.
- Room schema 2 migration retains alpha tasks, messages, conversation IDs and pending run receipts. No destructive migration fallback.

Validation: **23 unit tests and 10 connected Android 16 tests passed**; debug APK, Android lint and instrumentation compilation passed. The connected suite exercises migration from the real exported v1 schema, active-turn synchronization races, offline cache partitioning, all four themes, language modes and the new user flows.
