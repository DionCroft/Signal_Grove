# 1.1.0-beta.1 — Starhaven pixel interface and approved updates

This community preview adds original orbital-garden pixel art, Starhaven Grove, stepped panels/navigation and gentle motion with app/system reduced-motion support. Your saved palette remains selected; choose Starhaven Grove in Appearance for the new warm palette.

Settings → App updates checks public GitHub releases on open/resume at most daily. Review a release before approving its private verified download and Android installer. Stable updates are selected initially; preview updates are optional. Installation waits for active app work, verifies package/version/checksum/current signer, and requires Android’s source permission and confirmation. No Hermes credentials are sent to GitHub. Older 1.0.0 installations need to install this preview once to gain the updater. [Update guide](../APP_UPDATES.md).

The broader Hermes audit follow-up is included as implemented so far and remains in progress. This beta is not a claim of complete feature parity or a replacement of stable 1.0.0. Remote features still depend on the Hermes host’s supported API and configuration.

Validation: strict required Android build/lint, 330 JVM checks, complete 498/498/499 local suites on API 26/36/37, actual approved APK replacement with retained data on all three, narrow 130% text and wide-layout checks. The final signed production APK upgraded public 1.0.0 in place and retained a synthetic task. [Detailed evidence](../VALIDATION.md#pixel-interface-and-approved-github-updates--110-beta1-2026-11-04). Public exact-commit CI is a required publication gate and is linked in the GitHub release notes.
