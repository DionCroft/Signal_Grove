# 0.4.0 — Notifications, task widget and automation controls

- Explicit notification opt-in with Android permission and settings access. WorkManager checks local due/overdue tasks and optionally reads tracked server run outcomes or pending decisions. Notices contain generic status, not task titles, prompts or replies. Durable receipts deduplicate checks. Disable cancels work and notices.
- Local-task home-screen widget shows open/due counts, refresh and navigation to Tasks. No credentials, task titles or notes appear in the widget. English/Chinese compact text and full multilingual accessibility labels fit the widget. Launcher pinning is offered where supported.
- Profile-specific opt-in to create/edit/pause/resume/run/delete Hermes jobs, each with a review and confirmation. New jobs start paused with local delivery. A blank replacement schedule preserves existing fields; other advanced server fields are never overwritten. The server validates schedule syntax and timezone.
- Job mutations are sent once. Durable receipts retain uncertain outcomes across restart and block further changes until explicit server review. Refresh failures after a confirmed action do not repeat it. Demo changes are clearly simulated and reset on Demo restart.
- URL, token and debug transport policy now form one atomically stored, Keystore-encrypted vault record. Legacy token storage is migrated by the foreground app. Workers never pair a separately read URL with a token. Schema 3→4 preserves pending controls, tool events and run cursors.

Validation: **39 unit tests and 26 Android 16 connected cases passed**. Debug build, lint and instrumentation compilation passed; APK signature verified. New cases exercise exact job routes/methods, bounded bodies, malformed acknowledgements without replay, durable uncertain actions, concurrent credential pairing, schema-3 preservation, actual private notification delivery/deduplication, widget provider/rendering, and confirmed Demo job flows. Public CI must pass before publication.

Development release. Checks are best effort, approximately every 15 minutes, subject to Android battery, force-stop, permissions and network limits; this is not server push or an exact alarm service. Workers only read tracked run IDs and never execute runs or resolve approvals. Notices open Tasks or Chat; select the relevant conversation to reconcile its transcript. The widget does not complete tasks outside the app. No live Hermes or physical audio hardware was supplied; contract/emulator validation is distinct from live compatibility.
