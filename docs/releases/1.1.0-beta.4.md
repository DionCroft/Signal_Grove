# Signal Grove 1.1.0-beta.4

Signal Grove now checks releases at the canonical **DionCroft/Signal_Grove** repository and shows that source before an approved download. The Android app, help and community documentation use the new name. Production and debug packages, original signing keys, existing private data identities and APK filenames are retained.

## Upgrade from beta.3 or earlier

Older previews contain the former fixed update-feed address and cannot adopt GitHub's repository redirect. Download the matching APK below once and install it over the existing app; Android will ask for approval. Choose the production APK for the normal app, or the `-debug.apk` only for an existing development installation. Do not uninstall first. Following this signed upgrade, in-app update checks use the canonical Signal Grove feed.

This preview also includes scoped stored project inventory/details and the internal one-send project mutation foundation. The project screen remains read-only on this release. Project write forms, home-aware receipt review UI, broader Hermes parity and live-host/physical-device certification remain subsequent audit work. Existing chat working directories are unchanged.
