# Signal Grove 1.1.0-beta.8

Signal Grove 1.1.0-beta.8 · Android version code 111.

- **Automatic model selection:** choose **Chat → sliders → Automatic · use serving model → Apply to new turns** on an existing connection. New connections use Automatic by default. New turns resolve a fresh authenticated serving-model observation when supported; unavailable or ambiguous status holds the draft. Existing session locks take precedence. Frozen requests keep their original body and key.
- **Reasoning and service presets:** choose the settings supported by your Hermes server from menus. Server default remains available. No loaded weights or saved server default is changed.
- **Existing conversations and projects:** browse saved histories across Hermes interfaces. Histories belonging to other interfaces are read-only. Hermes management reads stored project metadata; worker files and execution require their separate scope and tools.
- **Safe read recovery:** interrupted identity/profile reads can recover without repeating session mutations or uncertain work.

### Download and update

Download **hermes-agent-mobile-1.1.0-beta.8.apk** and install it over your existing production Signal Grove app. Keep the same package and signing identity; do not uninstall to update. The optional `-debug.apk` is a separate debug package. Technical APK filenames retain the convention required by already-installed updaters. Stable 1.0.0 remains the latest stable release.

### Known limitations

Locally cached conversations may remain after the connected server no longer lists or serves them. Opening an unavailable entry can report `session_not_found`; its error banner can remain after another conversation successfully loads. Local cached data is preserved. Clear the old banner when reviewing the later result. Stale-entry feedback is tracked in the continuing audit.

The new canonical viewer and room browser are separate unreleased work. OEM background delivery, Bluetooth/voice and the Android updater's final installer flow are not covered by these release checks. On-device-only speech remains dependent on installed device support.
