# 0.3.0 — Voice, tool activity and explicit decisions

- Foreground speech input defaults to on-device-only; unavailable local recognition is explained. English/Chinese transcription remains editable before sending. Optional read-aloud uses installed language voices, excludes network voices by default, supports speed/stop and bounded Unicode-safe chunks, and stops on background/exit.
- Durable tool activity records show timestamps, duration and bounded visible output. A failed tool is distinct from the final run outcome; private reasoning is not displayed.
- Durable approvals and clarification requests require explicit individual responses. Only allow-once/deny are supported. The client verifies the current prompt identity, execution generation and visible contents before responding. Ambiguous delivery requires status review and never automatically retries a decision. Resolved tombstones prevent stale polling from resurrecting decisions.
- Runs resume from a transactionally saved sequence cursor. Replayed events are deduplicated. Replay gaps switch to status-only recovery; they never trigger new work. Advertised unknown-run acknowledgement is explicit and confirmed. Schema 2→3 preserves tasks, job snapshots and run receipts.
- Demo includes harmless approval and clarification exercises with no agent execution or microphone access.

Validation: **33 unit tests and 20 connected Android 16 tests passed**. Debug build, lint, instrumentation compilation and APK signature verification passed. Real-client fixture tests verify HTTP→ViewModel→Room reconnect without a second admission or duplicate output, plus replay-gap recovery. Device tests cover durable decisions, migrations, Demo approval/clarification and typed speech review. Public CI is checked before publication.
