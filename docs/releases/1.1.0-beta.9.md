  inference. Reviewed LFM3 download and compatible GGUF imports; context limits,
  explicit load/unload/delete, resume/discard, licence/hash/size/template checks.

  Advice cannot execute tools, change configuration or approve work.

  remote history and attempted/unknown work are excluded; no silent replay or
  automatic cloud fallback.

  stored uncompressed/aligned, increasing APK size. Original package IDs, signing
