# Signal Grove 1.1.0-beta.9 candidate

**Unpublished preview, versionCode112.** [Beta.8](https://github.com/DionCroft/Signal_Grove/releases/tag/v1.1.0-beta.8)
remains the public preview. There is no public beta.9 APK download yet.

## Implemented candidate features

- Optional separate phone chat/history with native, streamed, cancellable text
  inference. Reviewed LFM3 download and compatible GGUF imports; context limits,
  explicit load/unload/delete, resume/discard, licence/hash/size/template checks.
- A static setup guide and versioned, grounded onboarding/troubleshooting helper.
  Advice cannot execute tools, change configuration or approve work.
- Explicit draft/clipboard handoff between local advice and Hermes. Credentials,
  remote history and attempted/unknown work are excluded; no silent replay or
  automatic cloud fallback.
- Newer canonical conversation/room viewing and project navigation, with advertised
  capability/authentication boundaries. Project metadata is not worker ownership.
- Startup packaging fixes and bounded cancellation under saturated I/O. DEX is
  stored uncompressed/aligned, increasing APK size. Original package IDs, signing
  keys and Android8 minimum remain.
