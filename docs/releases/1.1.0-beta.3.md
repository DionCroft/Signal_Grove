# Signal Grove 1.1.0-beta.3

This preview introduces the Signal Grove name throughout the native client and current documentation. Android labels, the app header and compact rail mark, notifications, update approval text, sign-in callback and task entry points use the new brand. The header wraps to preserve the full name and version on narrow screens and at larger text sizes.

VersionCode **104**. Existing production/development package identities, original signing keys, private storage and task-backup markers are preserved. Existing installations can receive this preview through **Settings → App updates → Include preview releases**. The public update feed and exact APK filenames retain their compatibility names; see [branding](../BRANDING.md).

Hermes Agent remains the name of the upstream backend. This rename does not claim new backend feature parity. The long-horizon integration/automation audit continues.

Build, runtime, screenshot and original-signer upgrade evidence are recorded in validation before publication. Exact release-commit Android and compatibility CI remain publication gates.

The initial upstream-main compatibility gate caught browser cookie-write hardening. Its [pinned source review](../contracts/2026-11-04-browser-cookie-write-review.md) records the unchanged native bearer path and exact accepted handler variant, without changing Android wire behavior or the original baseline.
