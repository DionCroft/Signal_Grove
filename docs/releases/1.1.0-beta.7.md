# Signal Grove 1.1.0-beta.7 — existing Hermes chats

**Preview candidate, Android code 110.** The GitHub release page is authoritative for publication, final checks and APK digests. Install the matching production or debug variant over the existing app with its original signer; retain app data.

Conversation history now includes Desktop, Discord and other Hermes origins, alongside API conversations. Search and source filters apply to loaded rows; More loads older pages. Existing messages are imported through authenticated reads. Foreign and unknown origins remain read-only, with a compact explanation control; continue them in their original client or start an API conversation. API chats retain their normal reply path and conversation identity. No automatic replay, foreign-session fork or server ownership change is introduced.

Multilingual history controls share one scrollable body. More and Close remain reachable with the keyboard open, including the API26 large-font layout. The full read-only reason remains available without crowding chat messages. Management reviews also observe generation changes even when their visible state is identical, preserving stale-review invalidation.

For an existing installation, keep Tailscale connected, configure the private API root without an extra `/v1`, and sign in separately to the private management dashboard. Review provider and model IDs from the catalog together. The serving model, saved server default and conversation request can differ; no model weights or server defaults are changed automatically.

Host project inventory/details expose metadata after explicit read review. They do not adopt a Windows/NAS working directory into a phone chat or prove worker execution. Canonical shared Bot Chat admission and verified worker handoff/file access remain separate audit work. No engineering files or production server configuration were changed for this release.

Focused local validation passed the four required Gradle tasks, 548 JVM cases and all 18 origin/history/title cases on each owned API26/API37 emulator. Real Android-input paging/Close with an open keyboard and fresh controlled screenshots were checked. Earlier failed runs remain retained. Exact-source full hosted CI, original-key signed production checks and retained-data physical upgrade remain required before publication; this source document does not pre-claim those gates.
