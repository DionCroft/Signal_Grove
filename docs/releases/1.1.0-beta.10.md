# Signal Grove 1.1.0-beta.10

This prerelease focuses on optional on-device AI and responsive phone
controls. The production package uses version code 115 and the
existing signing identity. The APK is built for Android 8 and newer.
On-device inference requires a compatible 64-bit device and a separately
downloaded or imported model.

## What's included

- Edit, regenerate and branch local chat. Search and organize history,
  export Markdown, and review a passphrase-protected backup or restore.
- Pick earlier turns or review a summary before continuing in a separate chat.
- Use the pinned LFM3 and Qwen catalogue, manage reviewed downloads and
  GGUF imports, and select per-model context and performance settings.
- Ask questions about selected local documents, use writing tools and
  foreground temporary chats, and review personal context before using it.
- Open Chat options and Voice while editing on compact screens. Offline
  dictation and read-aloud depend on the compatible services installed on
  the device. The setup guide and troubleshooting checklist work unloaded.
- Use the verified llama.cpp b12556 native runtime update.
