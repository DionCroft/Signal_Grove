# Signal Grove 1.1.0-beta.6 — new conversation title fix

**Preview, Android code107.** Install the same APK variant over your existing app
to retain its data. Use `-debug.apk` for a development installation and the APK
without `-debug` for production. Original package and signing identities remain.

Opening several new conversations with the same text (for example, “Test”) could
make Hermes reject the second session with HTTP400 `invalid_title`: titles are
unique on Hermes. New native conversations now use a readable single-line label
with a stable suffix derived from their newly chosen session identity. Unicode
truncation preserves complete code points. Only the label changes; the full user
message, existing sessions and their history are preserved. No automatic turn
replay or server title-rule change is introduced.

The verified serving model and saved Hermes default can legitimately differ.
This title error occurs before model inference; it is separate from an offline
default endpoint. To use a different available model, review a provider/model
choice and apply it to new turns. The app does not silently load weights, clear
session locks or change the server default. Existing session locks still take
precedence. [Model status and scope](../RUNTIME_MODEL_STATUS.md).

Release checks and exact APK digests are recorded on the GitHub release page
after successful exact-source hosted CI, original-key production assembly and
lint, package/signature review and retained-data upgrade verification. This
source document does not pre-claim those gates or physical/OEM acceptance.

The broader Hermes parity audit continues. Unrelated task-override form work is
kept on its feature branch and is not part of this hotfix.

The title regression fixture explicitly reads the advertised model catalog, so
that path is exercised consistently after other screens. Its corrected companion
passed the34-case prior failure sequence on a separate fresh API37 target. The
original staged app is retained after complete code/resource payload and signer
comparison with the rebuild. Full corrected-head CI remains a publication gate.
