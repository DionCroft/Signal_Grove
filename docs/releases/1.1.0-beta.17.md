# Signal Grove 1.1.0-beta.17

[Download the signed APK](https://github.com/DionCroft/Signal_Grove/releases/download/v1.1.0-beta.17/hermes-agent-mobile-1.1.0-beta.17.apk) · [GitHub release and checksums](https://github.com/DionCroft/Signal_Grove/releases/tag/v1.1.0-beta.17)

Signal Grove adds Quick Capture, project notebooks and a Today inbox. Android 8
and later. On-device model inference requires a compatible 64-bit device.

- Keep, search, edit and archive local captures. Add optional English packs for
  offline screenshot OCR and short voice-note transcription. Review extracted
  tasks before adding them.
- Organize captures in notebooks, choose excerpts for cited local answers, and
  review the selected context before sending it to Hermes.
- Export selected workspace records with passphrase protection. Restore with a
  preview of the selected rows and ID conflicts.
- See local work and scoped Hermes approvals in Today. Open a specific older
  run's saved receipt and review an approval from its owning profile.

The GitHub updater offers previews through **Settings → App updates → Include
preview releases**. Direct installation uses the same package and original
signing key. The release includes the APK, SHA-256 checksums, signing certificate,
runtime SBOM and provenance.

## Verification

The standard device matrix passed 1,281 Android 8 cases and 1,282 Android 17
cases. The archived JVM run passed 1,279 cases. Release lint passed, and the
signed APK uses the original Signal Grove package and certificate.
[Android test results](https://github.com/DionCroft/Signal_Grove/actions/runs/46079905078).

The published beta.16 upgraded in place on an Android 17 emulator and a
Xiaomi phone. The Xiaomi kept its package and data-directory identity,
showed retained task data, connected to its saved Hermes server, and opened
history. The full previous-chat and offline-data comparison remains open.

On Android 17, the installed beta.16 updater discovered the public preview,
downloaded and verified the APK, and opened Android's update confirmation.
The installed APK matched the published SHA-256. The app kept its UID,
first-install timestamp and a saved test task.

All five release assets downloaded anonymously and matched their staged hashes.
