# 1.0.0 — Stable community release

The four planned milestones are implemented: session/task/job management (0.2), foreground voice and durable tool decisions/recovery (0.3), opt-in notifications/task widget/confirmed automation (0.4), and this documented signed community release.

- Signed, non-debuggable production APK with trusted HTTPS only. Separate debug APK retains the development signing certificate for upgrades from 0.4.0. The private production key stays outside Git in ignored owner-controlled storage.
- Reviewed task export/import through Android's file picker enables debug→production migration. Bounded, versioned UTF-8 JSON excludes credentials/chats/jobs. All rows are validated before a confirmed atomic merge; matching IDs are updated and other tasks remain.
- Consent rechecks identity, generation, full visible prompt and current choices. Missing/oversized/unsafe consent cannot authorize tools. Malformed bearer values fail with a generic message. Stable protocol recovery, encrypted connection pairing and schemas 1→4 remain covered.
- Current phone/tablet/large-text screenshots, a user guide, compatibility contract, security policy with enabled private vulnerability reporting, and a repeatable signing/release process.

Validation: **43 unit tests; 30 device cases on Android 16/API 36; the same 30 on Android 8.0/API 26; 5 additional large-text and 5 tablet UI cases — all passed.** Debug/release build and lint passed. Signed production APK installed and launched on both Android versions. Production file-picker export/review/import was exercised with synthetic task/notes and verified without duplicates. APK signature schemes/manifests and debug upgrade certificate were checked. Public CI is verified for the release commit before publication.

Install `hermes-agent-mobile-1.0.0.apk` for production (`org.hermesmobile.app`). Existing development installs can use `1.0.0-debug.apk` (`org.hermesmobile.app.debug`) to retain data, or upgrade debug then export tasks and import into production. Reenter the server connection; API-owned sessions can be reimported. Purely local conversation caches are not transferred between packages. See the [user guide](https://github.com/DionCroft/Signal_Grove/blob/main/docs/USER_GUIDE.md) and [signing/release guide](https://github.com/DionCroft/Signal_Grove/blob/main/docs/RELEASING.md).

Compatibility limits are explicit: no supplied live Hermes endpoint/credentials or physical audio hardware were used. Fixtures/emulators do not establish every provider/device's speech or server behavior. On-device speech requires a supporting Android 12+ service/model; online recognition/voices are explicit. Background notices are read-only best-effort WorkManager polling, not push or exact alarms. This is an independent MIT community client, not endorsed by NousResearch, and is distributed through GitHub rather than the Play Store.
