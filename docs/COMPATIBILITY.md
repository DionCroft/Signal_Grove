# Compatibility and protocol scope

Android 8.0/API 26 minimum; compile/target API 37. Foreground local-only speech needs Android 12/API 31 plus an installed service/model. System recognizer and TTS availability vary by device. Network speech is explicit; physical audio quality is not inferred from text/policy tests.

The app follows the [official Hermes API server reference](https://hermes-agent.nousresearch.com/docs/user-guide/features/api-server/) and the upstream gateway/pending-control contracts reviewed during these milestones. No minimum Hermes version string can establish all feature support across changing/forked installs: authenticated capability discovery chooses native sessions/Runs, session streaming or OpenAI-compatible fallback. Unsupported routes remain explicit. Exact unknown-run acknowledgement is exposed only when advertised. Jobs use documented bearer-protected routes after per-connection opt-in; no invented `jobs_admin` capability is assumed.

API-owned sessions are supported; imported CLI/Desktop shared ownership is outside scope. Compatibility completion responses do not prove tool/run completion. Native Runs support persisted request keys and sequence-based manual resume; expired receipts/event buffers require server review. Jobs preserve unedited fields. No OAuth, file/image attachments, remote agent backend, automatic approvals or server-push service is included.

The shipped Demo is a local simulator. Fixture tests validate request/response and lifecycle behavior without a production agent. The owner's live endpoint/credentials and physical microphone/speaker hardware were not supplied. See the release validation record for device matrix, exact counts and any remaining manual checks.

Development `1.1.0-dev` adds read-only `GET /health/detailed`, `/api/model/options`, `/v1/skills` and `/v1/toolsets`, exposed when their endpoint entries are advertised. Each configured prefix and bearer credential is retained. A successful HTTP diagnostic response may report degraded readiness. The catalog includes unavailable/unauthenticated providers and optional capability/pricing hints; those are server metadata, not a guarantee of runtime availability or cost. Integration execution still happens on Hermes using its configured API-server toolsets.

Schema 5 preserves earlier sessions/receipts while adding a request hash and optional stable channel key. Full requests are bounded to 10 MB outside Room rows; text messages are capped at 64000 UTF-16 code units. The exact header/body is reused on a missing-ID Runs recovery within the existing 23-hour client window. The server's retention/admission guarantees still govern replay. Image picking remains a pending implementation chunk; requested model overrides are now implemented.

Requested `model`, `provider` and `model_options` are now supported on Runs, session chat and compatibility requests when model-option support is advertised. The client emits only the documented reasoning enabled/effort and service-tier option fields. No model/provider SDK or provider credentials are installed on the phone. Choices are requests; session locks, routes and server/provider validation still apply. Advertised per-session locks, forks and active-run steering use exact acknowledgements and durable no-replay operation receipts. Schema 6 adds bounded cached metadata and these receipts. There is no verified clear-lock route. Forking marks the original session branched on Hermes. Steering acceptance is not execution completion. Legacy compatibility chats keep local history and cannot target native session controls without verified native identity.

Android 17/API 37 requires explicit local-network permission for LAN/private-address connections. Settings can request it or open system app permissions; denial does not block public internet endpoints. Permission-aware DNS also detects public-looking names resolving to private addresses. Loopback traffic remains device-local. The operating system enforces permission changes on sockets; a socket blocked after revocation may still surface as a generic network timeout. No permission dialog is launched from startup, a worker, or an uncertain operation replay.
