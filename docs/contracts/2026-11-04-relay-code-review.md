# Team Gateway link-code source review

Reviewed 2026-11-04 against stable **b200f5bc60e31588ba2cb60e288029c4a54ba5fa** and matching current main relay file blobs. Original F0 fingerprints/fields/source hashes and all previous variants remain unchanged. Four exact B200 AST variants select `relay_routes:request_relay_link`, `relay_routes:get_relay_link_state`, `channel_relay_links:request_link` and `channel_relay_links:link_code_state`. Their modules were already explicitly recorded absent at F0; no fabricated original hash, moving-ref acceptance or new source module is introduced. Current coverage is **1,739 fingerprints / 237 fields / 65 routes / 133 modules**.

The POST route forwards `action=request` and exact platform through the process-home control socket, without declaring profile/body. The client sends `{}` and enforces the existing positive launch-home proof plus original actor/home/fronted modes/connector authority/reported bot context before one durable claim. `request_link` checks fronted platform, then Portal authority, before connector `/manage/link`. Only typed JSON 409 detail slugs `platform_not_fronted` and `managed_by_portal` can prove a pre-mint refusal. Other failures can follow minting and remain unknown, without an automatic replacement key. The mandatory reply is exact platform, bounded opaque code and exact `/link CODE`; no generic `ok`, account echo, server revision or idempotency token is invented.

Creation contains no redemption state: local **unverified** is explicit. Mandatory ACK precedes optional expiry/bot parsing, encrypted local recovery and post-read scope verification. A fresh creation proof can expose the issued command as unchecked, while sharing always requires a new original-code state check. Optional expiry or URL failure cannot undo ACK. Valid earlier ISO expiry shortens the local 15-minute cap; otherwise the device-clock cap applies. Unsupported browser links remain unavailable with manual copying, and code-cache failure leaves known issuance without a fabricated recoverable original.

The GET state route forwards the original code only. Its helper calls connector `/manage/link/state` and returns reported state or inactive, plus optional reason. Pending/inactive/refused are observations; inactive is used **or** expired and never a linked/owned/delivered result. The original receipt/capability must still bind the exact credential, actor, URL/profile/home/fronted modes and bot context. Scope is verified before the private request and afterward. Room transactions prevent late pending from reopening inactive/refused; later fresh original-receipt reads also prevent restoration if private-cache deletion failed. Local expiry/clear never becomes a remote inactive/canceled result.

Original capabilities are stored separately with Android-keystore AES-GCM encryption, original-owner binding, 32-per-owner/128-global live limits, expiry cleanup and no silent live eviction or value replacement. Room keeps only platform/modes/home context and typed issuance/refusal/state flags, with no code/command/bot URL/reason or hashes of private values. Resume is local metadata only, followed by explicit original status verification before secret exposure. Close/switch/cancel/auth failure discard private RAM references; expiry/clear/sign-out/forget govern encrypted copies. No code paste, background polling, automatic browser/message, invented cancel route or unknown replay is exposed.

Reviewed clipboard and bot actions recheck the same original capability, pending report, scope, exact URL, expiry and resumed foreground. The supported destination policy follows upstream Telegram/Discord/WhatsApp HTTPS formats, with strict authority/path/query limits and WhatsApp command equality. A browser receives no Hermes bearer; WhatsApp may prefill a compose screen, but the app sends no message. A pending report is not a lease against later redemption/expiry, and no host CAS exists. Malicious/changing deployments, hidden bot or authority changes after checks, proxy/filesystem aliases, runtime gateway ACLs and external server logging policy remain outside the static/local guarantee.

The new source regression changes sixteen guard/forwarding/payload/state semantics and requires review. Exact per-API, private-cache, Room/transport/UI and unmodified-CLI evidence is recorded in [VALIDATION.md](../VALIDATION.md). Stopped-gateway HTTP checks do not prove positive live minting, Android-to-Hermes, vendor/Portal/TLS or physical-device behavior.
